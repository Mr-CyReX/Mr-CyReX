### Current work

> Most of my current systems work is private. These are the systems I actively build and use.

**Hexus**  
Native agent/work harness built around structured state, direct machine capabilities, workspace orchestration, and human/agent collaboration.

**Computer Control MCP**  
Windows-native control plane for agent sessions, process control, IPC, operator notes, logs, safety gates, and deterministic computer interaction.

**OpsDesk**  
Native internal-operations application built with Rust + GPUI + SQLite. Role-based authentication, approval workflows, validated imports, attachments, audit history, exception queues, and local-first data ownership.

**Rill**  
Native music-player experiment focused on GPUI, custom Rive rendering, window motion, transitions, and lightweight desktop UX.
